Install guide

Turtle coding — local laptop setup (Node, Arduino CLI, CP210x USB-UART)

← Coding · Agenda · Markdown copy

Students only need this project folder. Upload works in Chrome or Edge on the same PC as the USB cable.

1. Node.js and npm

Windows nodejs.org LTS installer, or winget install OpenJS.NodeJS.LTS
Mac nodejs.org LTS, or brew install node 
node --version
npm --version

2. Once per laptop (in this folder)

npm install
npm run setup:cli

Installs Arduino CLI (if on PATH), Uno core, Servo, and IRremote 2.6.1.

Windows — Arduino CLI Install guide or winget install ArduinoSA.CLI
Mac — Arduino CLI brew install arduino-cli

3. CP210x USB-UART driver (Silicon Labs)

The Turtle board uses a CP2102 chip. Install the VCP driver once: Silicon Labs CP210x drivers.

Windows — which port?

  • Device Manager → Ports (COM & LPT)
  • Look for Silicon Labs CP210x USB to UART Bridge (COMx)
  • When you click Upload to Turtle, pick that CP210x entry in the browser dialog

Mac — which port?

  • After installing the driver, plug in USB
  • Typical device name: /dev/cu.SLAB_USBtoUART (check with ls /dev/cu.SLAB*)
  • Allow the driver in System Settings → Privacy & Security if macOS prompts
  • Upload picker shows the SLAB / CP210x port — select it there
Before every upload: unplug the Bluetooth module on the robot. TX/RX are shared with USB serial.

4. Every class session

npm run dev

Open http://localhost:5173/code.html → snap blocks → Upload to Turtle.

5. Troubleshooting

  • No Upload button — use npm run dev, not opening HTML as a file.
  • No ports listed — reinstall CP210x driver; try another USB cable or socket.
  • Compile fails — run npm run setup:cli again with internet.
