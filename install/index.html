Offline classroom kit

Everything needed without internet lives under offline/ in this project (bring on a USB stick).

offline/node/ Node.js (includes npm) — only if Node is missing
offline/npm/ Project packages (node_modules.zip), not a second npm. Versions: Blockly ^12.3.1, Express ^5.2.1, Vite ^7.1.7, webserial-flasher ^1.0.1, @types/express ^5.0.6
offline/arduino-ide/ Arduino IDE 1.8.19 (includes Uno / AVR boards)
offline/drivers/cp210x/ Silicon Labs USB-UART drivers (Windows + Mac)

Windows — once per laptop

powershell -ExecutionPolicy Bypass -File scripts\offline-setup.ps1
  1. Run the script above (extracts node_modules).
  2. Install offline\arduino-ide\arduino-1.8.19-windows.exe.
  3. Unzip and install offline\drivers\cp210x\CP210x_Universal_Windows_Driver.zip.
  4. Device Manager → Ports → should show Silicon Labs CP210x (COMx).

Mac — once per laptop

bash scripts/offline-setup.sh
  1. Run the script (extracts node_modules).
  2. Install from offline/arduino-ide/arduino-1.8.19-macosx.zip.
  3. Install offline/drivers/cp210x/Mac_OSX_VCP_Driver.zip; allow in Privacy & Security if asked.

Every class session

npm run dev

Open http://localhost:5173/ → Home → Code.

Upload (offline-friendly): In Coding click Download .ino → open in Arduino IDE → Board Arduino Uno → Port CP210x → unplug Bluetooth → Upload.

CP210x port names

  • Windows: Device Manager → Silicon Labs CP210x USB to UART Bridge (COMx)
  • Mac: often /dev/cu.SLAB_USBtoUART — pick it in Arduino IDE → Port
