Local class kit for the Turtle robot — blocks, upload over USB, and the same project agenda used in Foundation.

Code

Projects

Agenda

Setup

Install guide

Node, Arduino IDE, CP210x USB-UART — offline copies under offline/ for classrooms without internet.

Class session: from this folder run npm run dev, then open http://localhost:5173/. In Code use Download .ino, then upload with Arduino IDE (Uno + CP210x). Unplug Bluetooth first. Offline setup: Install guide.
