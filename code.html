8×8 face

Draw upright here. The kit face is mounted upside down — Upload flips it for you.

Motors

If motors are on the other side or the robot drives the wrong way, change this then Upload again.

Line sensor

Switches how the sensors decide they are on the tape. If line-follow ignores the path or treats the floor as the line, try the other setting, then Upload again.

Setup
  1. Use Chrome or Edge on a laptop (not a phone).
  2. Install tools once — see Install guide (Node, Arduino CLI, USB-UART driver).
  3. Plug in the Turtle USB cable. Unplug Bluetooth on the robot.
  4. Run npm run dev and open http://localhost:5173/code.html, then Upload to Turtle.
